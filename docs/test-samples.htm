Тестові приклади кваліфікованого електронного підпису

Тестові приклади для перевірки правильності реалізації форматів, протоколів та інтерфейсів технічними засобами кваліфікованого електронного підпису та технічні специфікації, розроблені відповідно до стандартів, які визначають вимоги щодо забезпечення сумісності, опубліковані на виконання наказу Міністерства цифрової трансформації України від 28.12.2023 № H 191 «Деякі питання реалізації вимог стандартів, у тому числі щодо забезпечення сумісності»
